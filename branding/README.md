# OneBoard branding assets

`OneBoardSafePaste.ico` is the repository copy of the OneBoard icon master used to
create this branding baseline.

Master source SHA-256:
`3ECE0692B4502129CB8C4CB6A97062EC241FCA614A2BAE9B8CA6E71BA4AFC6DA`

The master file is not modified by the build. `build/appicon.png`, the frontend logo,
and the Windows package images are generated from the repository copy. Wails uses
`build/appicon.png` to generate Windows executable icon resources during each clean build.
